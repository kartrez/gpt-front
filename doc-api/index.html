Документация API

REST API для работы с чат-ботами и RAG-системой. Совместимо с OpenAI Chat Completions.

Начните с создания API ключа
Все запросы авторизуются Bearer-токеном. Сгенерируйте ключ в личном кабинете и подставьте его в заголовок Authorization.
Войти и создать ключ
Авторизация

Все запросы используют Bearer-токен. Управление ключами — на странице API Ключи . 

Authorization: Bearer YOUR_API_KEY
Формат ошибок

Все ошибки приходят одним объектом с полем message — его достаточно, чтобы показать человеку причину. Если ошибка относится к конкретным полям запроса, рядом лежит errors с разбивкой. 

{
  "message": "Запрос отправлен к модели `nope/nope`, которой нет, проверьте на сайте поддерживаемые модели https://gpt-chat.by/pricing",
  "errors": [
    { "field": "model", "message": "Запрос отправлен к модели `nope/nope`, которой нет..." }
  ]
}
КодКогда
400
Неверный запрос: неизвестная модель, пустой или слишком длинный промпт, неподдерживаемый файл, нарушение любых ограничений полей
401
Нет заголовка Authorization, ключ не найден, отозван или просрочен
402
Не хватает баланса на оценочную стоимость запроса. В теле есть balance, estimatedCost и shortfall
403
Ключ есть, но доступа к этому ресурсу нет
404
Объект не найден: чужая или удалённая коллекция, истёкшая задача генерации
429
Слишком часто. Действует на распознавание речи, презентации и разбор брендбука
500
Ошибка на нашей стороне — запрос можно повторить
Любая проблема с телом запроса — неизвестный слаг модели, пустой промпт, неверный формат файла — это 400. Отдельного кода 422 у API больше нет.
Формирование сообщений

Запросы строятся на основе массива messages. Каждое сообщение имеет role (system/user/assistant) и content.

Базовый пример отправки текстового сообщения. Текст поддерживают все модели. 
curl https://api.gpt-chat.by/api/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "google/gemma-4",
    "messages": [
      {"role": "user", "content": "Привет! Как дела?"}
    ]
  }'

Пример ответа 

{
  "id": "chatcmpl-123",
  "choices": [{
    "message": {
      "role": "assistant",
      "content": "Привет! У меня всё отлично, чем могу помочь?"
    }
  }]
}

Каталог моделей

Единственный достоверный источник слагов для параметра model: сейчас в каталоге 54 чат-моделей. Авторизация не нужна. Каталоги по типам генерации лежат на отдельных путях: /api/ai-models/images — генерация и редактирование картинок (18), /api/ai-models/videos — видео (23), /api/ai-models/audio — озвучка и музыка (7), /api/ai-models/transcribe — распознавание речи. Слаги из разных каталогов не взаимозаменяемы: модель для /chat/video не подойдёт для /chat/completions.

Chat completions

Отправляет сообщения в AI модель и возвращает ответ. Совместимо с OpenAI Chat Completions API. Перед вашими сообщениями сервис подставляет свой системный промпт: он просит модель рассуждать по-английски, а отвечать на языке пользователя (по умолчанию — русском), и при enableSearch=true добавляет текущую дату с требованием брать факты из результатов поиска. Этот промпт входит в prompt_tokens (~30 токенов) и не отключается — если нужен другой язык ответа, задайте его своим сообщением с role=system или прямо в тексте запроса.
